# BlinkIT-Data-Analysis
1.Project Title /Headline
BlinkIT Outlet Sales Data Analysis Dashboard
Example : This Power BI dashboard provides a comprehensive visual analysis of BlinkIT's sales data, covering outlet locations, fat content classification, item types, and sales quantities its  giving stakeholders a clear sales performance.

2.Short Description 
The BlinkIT Sales Dashboard is a visually engaging  powerful Power BI report designed to help users explore and compare sales performance across Tier 1, Tier 2, and Tier 3 outlet locations. The dashboard highlights key metrics including total sales by establishment year, outlet-level details, fat content breakdown, average customer ratings, total item count, and outlet type performance.

3.Tech Stack:
List the key technologies used to build the dashborad 
PowerBI Desktop - Main data visualization platform used for building the interactive report
power query - Data transformation and cleaning layer for reshaping and preparing raw data 
My SQL - Backend data source used to understand table relationships and query structured data
Excel  - Used for filtering, sorting, and importing CSV data as a pre-processing step
data modeling - Relationships established among tables like sales report, tier-wise performance, ratings, and top-selling products
